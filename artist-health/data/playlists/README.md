# playlists — קלט לדוגמה למנוע בריאות אמנים

כאן שומרים ייצוא של פלייליסטים אמיתיים מספוטיפיי, כדי לאמת את הפורמט האמיתי
לפני בנייה. קובץ אחד לכל פלייליסט (JSON או CSV).

## סוגי פלייליסטים ומחרוזת הזיהוי (לפי שם הפלייליסט)

- **שבועי סופי:** `彡 <טקסט> 彡 Week#NNN`
  לדוגמה: `彡 No Diggity 彡 Week#314`, `彡 The Space 彡 Week#321`
- **Outofplaylist (צל):** `#NNN Outofplaylist`
  לדוגמה: `#320 Outofplaylist`, `#319 Outofplaylist`

`NNN` = מספר השבוע (עולה ב-1 בכל שבוע).

## מה מספיק לי כדי לאמת פורמט

שלוש דוגמאות: שבוע רגיל אחד + פלייליסט אירוע אחד + פלייליסט Outofplaylist אחד.

> סטטוס: תכנון בלבד. עדיין לא נבנה קוד.
